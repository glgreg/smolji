# App Shell

## Purpose and Design Decisions

`src/app/` contém a camada de entrada do Next.js App Router (`layout.tsx`, `page.tsx`, `globals.css`):

- **Isolamento de SSR (`ssr: false`)**: O estúdio (`src/App.tsx`) acessa `localStorage`, `window` e `HTMLCanvasElement` imediatamente na montagem. Por isso, `src/app/page.tsx` é um Client Component (`"use client"`) que carrega `../App` via `next/dynamic` com `{ ssr: false }`.
- **Metadados e tipografia global**: `src/app/layout.tsx` define o `metadata` de SEO da aplicação (`MojiSnap - Customize & Convert Emojis to PNG Image Stickers`), carrega as fontes `Outfit` e `JetBrains Mono` do Google Fonts e aplica o estilo base `bg-zinc-950 font-sans antialiased`.
- **Estilização Tailwind v4**: `src/app/globals.css` configura o Tailwind CSS v4 e variáveis globais de estilo.

## Invariants

- `src/app/page.tsx` mantém a diretiva `"use client"` no topo e importa `../App` exclusivamente via `dynamic(() => import('../App'), { ssr: false })`.
- `src/app/layout.tsx` permanece um Server Component que exporta `metadata` estático e envolve `{children}` na estrutura `<html>` / `<body>`.

## Integration Contracts

- **Rota raiz (`/`)**: Renderizada por `src/app/page.tsx`, delegando toda a árvore de interface ao componente default de `src/App.tsx` (`studio`).
- **Estilos globais**: `src/app/layout.tsx` importa `./globals.css`, disponibilizando utilitários do Tailwind CSS v4 para todos os componentes filhos.

## Anti-Patterns

- Substituir o `dynamic(..., { ssr: false })` em `src/app/page.tsx` por um `import App from '../App'` estático: isso quebra a pré-renderização do Next.js durante `next build` por acesso a `localStorage` no servidor.
- Adicionar lógica de estado do editor ou manipulação de camadas em `src/app/page.tsx` ou `src/app/layout.tsx`: o shell deve permanecer mínimo e delegar o domínio ao módulo `studio`.
