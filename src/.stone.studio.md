# Studio

## Purpose and Design Decisions

`src/App.tsx` e `src/types.ts` implementam o **MojiSnap Studio**: um ambiente gráfico interativo em tela cheia para composição de stickers em múltiplas camadas.

- **Espaço de coordenadas canônico (`512x512`)**: Todas as posições (`x`, `y` relativos ao centro `256, 256`) e escalas (`256 * layer.scale`) das camadas são definidas sobre um artboard lógico de `512x512`. Na visualização interativa, o viewport aplica pan (`panX`, `panY`), zoom (`canvasZoom`) e `devicePixelRatio`; na exportação (`isExport = true`), o mesmo pipeline `render2D` escala proporcionalmente por `scaleFactor = targetSize / 512`.
- **Renderização Canvas 2D otimizada com `requestAnimationFrame`**: O pipeline ativo utiliza `CanvasRenderingContext2D` tanto para o preview interativo (permitindo desenhar guias pontilhadas, alças de transformação e sombras nativas) quanto para a exportação offscreen, preservando o framebuffer quando as dimensões do viewport não mudam e carregando imagens da CDN sob demanda com agendamento via `requestAnimationFrame`.
- **Histórico de edição e persistência local**: Pilhas de Undo/Redo (`undoStack`, `redoStack`) permitem reverter e refazer alterações de camadas. Tema (`mojisnap_theme`), chaves de API (`emoji_studio_keys`) e histórico de uploads (`emoji_studio_history`, limitado aos 10 itens mais recentes) são persistidos diretamente no `localStorage`.

## Invariants

- **Pelo menos uma camada ativa**: `deleteLayer` preserva no mínimo uma camada no estado `layers` (`layers.length <= 1` impede a exclusão), garantindo que o artboard nunca fique sem estado base.
- **Estilo inicial de licença aberta**: O estilo selecionado por padrão é `microsoft-3D-fluent` (MIT), atendendo às diretrizes de conformidade de copyright e AdSense descritas em `LEGAL_ANALYSIS.md`.
- **Paridade entre preview e exportação**: `render2D(ctx, size, null, true)` reproduz exatamente o recorte arredondado (`borderRadius`), fundo (`transparent`, `solid`, `gradient`), transformações matriciais (`translate`, `flipX`/`flipY`, `skewX`/`skewY`, `rotate`, `scale`), opacidade e sombras do preview, omitindo apenas o grid do viewport e as alças de seleção (`#eab308`).
- **Fallback tipográfico**: Quando uma imagem da CDN ainda está carregando ou falha (`img === 'failed'`), o canvas renderiza o caractere Unicode nativo com `ctx.fillText` para nunca deixar a camada invisível.
- **Compatibilidade com o gate de qualidade**: Nenhum arquivo em `src/` utiliza comentários `@ts-ignore`, `@ts-nocheck` ou `eslint-disable`, pois `scripts/remove-ignores.js` os remove antes do typecheck.

## Integration Contracts

- **Componente exportado**: `export default function App()` em `src/App.tsx`, consumido por `src/app/page.tsx` e testado em `__tests__/App.test.tsx` (que valida a presença do título `/MojiSnap/i` na montagem).
- **Tipos exportados (`src/types.ts`)**:
  - `Layer`: `{ id, emoji?, style?, x, y, scale, rotation, skewX?, skewY?, opacity, ... }`
  - `UploadedHistory`: `{ id, emoji, style, date, host, url }`
  - `ContextMenuState`: `{ visible, x, y, layerId }`
  - `DragState`: `{ layerId, type, mouseX, mouseY, layerX, layerY, layerScale, layerRotation }`
- **Chaves de `localStorage`**:
  - `mojisnap_theme`: `'dark' | 'light'`
  - `emoji_studio_keys`: JSON `{ imgbb: string, imgur: string }`
  - `emoji_studio_history`: JSON `UploadedHistory[]`

## Anti-Patterns

- Importar `src/App.tsx` em um Server Component sem `ssr: false`: a inicialização do estado lê `localStorage.getItem('mojisnap_theme')` diretamente, o que falha fora do navegador.
- Acoplar coordenadas de camadas às dimensões da janela (`viewportSize`): todas as coordenadas de `Layer` devem permanecer no espaço lógico `512x512` (origem no centro `256, 256`) para que exportações em `128px`, `256px`, `512px` ou `1024px` mantenham proporções idênticas.
- Desenhar indicadores de UI (bounding box ou handles) dentro do bloco `if (isExport)` de `render2D`: isso contaminaria os arquivos PNG, o clipboard e os pacotes ZIP exportados.
