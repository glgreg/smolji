# Emoji Utils

## Purpose and Design Decisions

`src/utils/emoji.ts` centraliza a inteligência de domínio sobre emojis, catálogos visuais e integrações HTTP externas para manter o estúdio (`src/App.tsx`) desacoplado de detalhes de protocolo e Unicode:

- **Segmentação Unicode precisa**: Emojis compostos (sequências ZWJ como famílias, profissões e tons de pele) são extraídos usando `Intl.Segmenter` com granularidade `grapheme`, garantindo que cada emoji composto seja tratado como uma única unidade em vez de ser quebrado em code points individuais. Um regex de fallback cobre ambientes legados sem `Intl.Segmenter`.
- **Resolução de ativos via CDN**: Gráficos rasterizados de emojis são carregados sob demanda a partir de `https://emoji-cdn.mqrio.dev/{encodeURIComponent(emoji)}?style={style}`, evitando empacotar gigabytes de assets locais.
- **Upload direto do cliente**: Os uploads para ImgBB e Imgur convertem `Blob` ou Data URL em Base64 puro (sem prefixo `data:image/png;base64,`) e enviam diretamente para as APIs públicas usando credenciais fornecidas pelo próprio usuário.

## Invariants

- `getEmojiUrl(emoji, style)` retorna string vazia (`''`) quando `emoji` é vazio/falsy e codifica o grafema com `encodeURIComponent` antes de interpolar na URL `https://emoji-cdn.mqrio.dev/`.
- `parseEmojis(text)` retorna um array de strings únicas preservando a ordem de aparição e mantendo sequências ZWJ intactas quando `Intl.Segmenter` está disponível.
- `uploadToImgBB` e `uploadToImgur` exigem chave/Client-ID não vazios e lançam `Error` descritivo caso ausentes ou caso a resposta HTTP indique falha (`!response.ok || !result.success`).
- `EMOJI_STYLES` mantém os identificadores exatos esperados pela CDN (`apple`, `google`, `microsoft-3D-fluent`, `twitter`, `openmoji`, `toss-face`, `whatsapp`, `facebook`, `animated-noto-color-emoji`, `telegram`, `serenityos`).

## Integration Contracts

- **Exports consumidos por `studio` (`src/App.tsx`) e `__tests__/emoji.test.ts`**:
  - `EMOJI_STYLES`: lista de `{ id, name, desc, format }`.
  - `GRADIENTS`: lista de `{ name, value, preview }` onde `value` é `'transparent'` ou uma expressão `linear-gradient(...)` com cores hex/rgb extraíveis pelo parser do canvas.
  - `POPULAR_EMOJIS`: mapa de categoria (`string`) para array de emojis (`string[]`).
  - `getGemojiList()`: retorna a lista de metadados do pacote `gemoji` (`{ emoji, names, tags, description }`).
  - `getEmojiUrl(emoji: string, style: string): string`
  - `parseEmojis(text: string): string[]`
  - `uploadToImgBB(image: Blob | string, apiKey: string): Promise<string>`
  - `uploadToImgur(image: Blob | string, clientId: string): Promise<string>`

## Anti-Patterns

- Dividir strings de emoji com `.split('')` ou `Array.from(text)` para extrair emojis: isso corrompe sequências ZWJ e modificadores de tom de pele.
- Enviar Data URLs completas (com o cabeçalho `data:image/...;base64,`) nos campos `image` das APIs do ImgBB ou Imgur: ambas as APIs esperam apenas o payload Base64 bruto.
- Embutir chaves de API padrão no código-fonte: as chaves de ImgBB e Imgur pertencem exclusivamente à configuração local do usuário (`localStorage`).
