# Identity

## 1. Purpose

**Smolji** (**Smolji Studio**) é um estúdio web interativo para converter, combinar e customizar emojis em stickers PNG de alta resolução com suporte a múltiplas camadas, fundos (transparente, sólido, gradiente), sombras, exportação em lote (ZIP com todos os estilos) e upload direto para provedores de imagem (ImgBB e Imgur). O valor central a preservar é a composição visual rápida, inteiramente client-side, sem necessidade de backend próprio.

## 2. Project Type

Frontend web application (Next.js App Router com renderização client-side em Canvas 2D / WebGL).

## 3. Audience and Maintainers

- **Usuários**: Designers, criadores de conteúdo, desenvolvedores de bots (Discord, Slack, Telegram) e streamers que precisam de stickers ou URLs públicas de emojis customizados.
- **Mantenedores**: Equipe/autor do repositório (`glgreg`), responsável por revisões de código e evolução do produto.

## 4. Lifecycle Stage

Active development — recém-migrado para Next.js 16 (App Router), TypeScript e Tailwind CSS v4, com suíte de testes em Vitest.

- **Versioning**: SemVer (`0.1.0` em `package.json`).
