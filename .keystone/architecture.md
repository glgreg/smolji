# Architecture

## 1. System Overview

Aplicação web single-page hospedada sobre Next.js App Router. Como o editor depende intensivamente de APIs exclusivas do navegador (`HTMLCanvasElement`, `localStorage`, `ClipboardItem`, `ResizeObserver`/`window`), a página raiz (`src/app/page.tsx`) carrega o componente principal `src/App.tsx` via `next/dynamic` com `ssr: false`. Toda a composição gráfica, manipulação de camadas, empacotamento ZIP e chamadas de upload ocorrem diretamente no cliente.

## 2. Technology Stack

- **Language / Runtime**: TypeScript 5 em Node.js / Browser (ES2017+)
- **Frameworks**: Next.js 16.2.10 (App Router), React 19.2.4, Tailwind CSS v4 (`@tailwindcss/postcss`)
- **Libraries**: `gemoji` (catálogo e shortcodes de emojis), `jszip` (exportação de pacotes ZIP), `lucide-react` (ícones)
- **Testing & Quality**: Vitest 4 com `jsdom`, `@testing-library/react`, `@vitest/coverage-v8`, ESLint 9 e `scripts/remove-ignores.js`

## 3. Structure and Patterns

- **Directory layout**:
  - `src/app/`: Shell do Next.js App Router (`layout.tsx`, `page.tsx`, `globals.css`).
  - `src/App.tsx`: Estúdio interativo de composição (estado de camadas, viewport com pan/zoom, pipeline de renderização Canvas 2D, atalhos de teclado, exportação e modais).
  - `src/types.ts`: Contratos TypeScript compartilhados (`Layer`, `UploadedHistory`, `ContextMenuState`, `DragState`).
  - `src/utils/emoji.ts`: Catálogo de estilos/gradientes, extração de grafemas (`Intl.Segmenter`), resolução de URLs de CDN e clientes de upload (ImgBB/Imgur).
  - `__tests__/`: Testes unitários e de componente (`App.test.tsx`, `emoji.test.ts`).
  - `scripts/remove-ignores.js`: Script executado antes dos testes para remover diretivas de supressão (`@ts-ignore`, `@ts-nocheck`, `eslint-disable`) de `src/`.
- **Data flow**:
  1. Entrada de texto ou seleção na biblioteca extrai emojis via `parseEmojis` / `gemoji` e adiciona camadas (`Layer`) ao estado do `App`.
  2. O loop reativo (`useEffect` -> `drawEditorCanvas` -> `render2D`) desenha o artboard lógico de `512x512` escalado pelo zoom/pan no canvas principal, buscando e cacheando imagens da CDN em `imageCache`.
  3. Ações de saída (`handleDownloadPNG`, `handleCopyToClipboard`, `handleDownloadZip`, `handleUploadImage`) renderizam um canvas offscreen na resolução `exportSize` sem os controles visuais de seleção.

## 4. Integration Points

- **Emoji Asset CDN**: `https://emoji-cdn.mqrio.dev/<emoji>?style=<style>` fornece os gráficos rasterizados para cada estilo suportado (`apple`, `google`, `microsoft-3D-fluent`, `twitter`, `openmoji`, etc.).
- **Image Hosting APIs**:
  - **ImgBB**: `POST https://api.imgbb.com/1/upload` (autenticado com chave configurada pelo usuário em `localStorage`).
  - **Imgur**: `POST https://api.imgur.com/3/image` (autenticado com `Client-ID` configurado pelo usuário em `localStorage`).

## 5. Constraints

- **Client-only rendering para o Studio**: `src/App.tsx` acessa `localStorage` e `window` na inicialização; deve sempre ser importado com `ssr: false`.
- **Zero-ignore gate**: `npm test` executa `node scripts/remove-ignores.js` antes de `tsc --noEmit`, `eslint` e `vitest run --coverage`, removendo automaticamente comentários `@ts-ignore`, `@ts-nocheck` e `eslint-disable` em `src/`.
- **Next.js 16 conventions**: Seguir os guias em `node_modules/next/dist/docs/` conforme estipulado em `AGENTS.md`.
- **Licenciamento de ativos**: O estilo padrão deve permanecer um conjunto de licença aberta (`microsoft-3D-fluent`), conforme documentado em [LEGAL_ANALYSIS.md](../LEGAL_ANALYSIS.md).
